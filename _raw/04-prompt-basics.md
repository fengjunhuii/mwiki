# Prompt 基础入门

## 简介

Prompt（提示词）是用户与大语言模型交互的输入文本。良好的 prompt 设计是获取高质量 AI 输出的关键。Prompt Engineering 的核心在于让模型准确理解用户意图。

## Prompt 的基本结构

一个完整的 prompt 通常包含：

1. **角色设定**：告诉模型以什么身份回答
2. **背景上下文**：提供必要的背景信息
3. **具体指令**：明确要求模型做什么
4. **输出格式**：指定回答的格式要求
5. **约束条件**：限定范围和边界

## 常见技巧

### 明确指令
将模糊的问题改为具体的指令。"写一篇文章"不如"写一篇 500 字的技术博客，主题是 Prompt Engineering，面向初级开发者"。

### 使用示例
提供输入-输出的示例，让模型理解期望的模式（few-shot learning）。

### 思维链
引导模型进行推理："请一步一步分析这个问题"。

### 迭代优化
根据输出结果不断调整 prompt，记录每次修改的效果。

## Prompt 设计的注意事项

- 避免歧义和模糊表述
- 不要在 prompt 中包含敏感信息
- 注意 token 限制（不同模型有不同上限）
- 测试不同表述对结果的影响

## 实用模板

```
角色：你是一位 [领域] 专家
任务：[具体任务描述]
上下文：[相关背景]
格式要求：[输出格式]
约束：[限制条件]
```
