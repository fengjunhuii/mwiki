## 常见模块分类参考

### 用户端模块
- 账号体系（注册、登录、找回密码、第三方登录）
- 首页 / 发现 / 推荐
- 搜索（搜索、筛选、排序）
- 详情页（内容展示、关联推荐）
- 购物车 / 收藏 / 关注
- 订单流程（下单、支付、发货、收货）
- 个人中心（资料、设置、消息）
- 消息通知（系统通知、业务通知）

### 管理端模块
- 用户管理（列表、详情、封禁、权限）
- 内容管理（发布、审核、上下架）
- 订单管理（查看、处理、退款）
- 数据统计（看板、报表、导出）
- 系统设置（配置、日志、备份）
- 权限管理（角色、菜单、数据权限）
