# ASCII 线框图指南

## 用途

在 PRD 中用 ASCII 字符画出关键页面的骨架结构，让开发者和设计师在动手之前对页面布局有一致的理解。

---

## 选择哪个页面

选用户最常停留的页面，或产品最核心交互发生的页面。一个关键页面就够了，不需要画所有页面。

---

## 要体现的信息

- 导航栏的位置和方向（顶部横向 / 左侧竖向 / 底部 Tab）
- 页面各区域划分（主内容区 / 操作栏 / 辅助信息）
- 视觉重心在哪里
- 是否有弹窗、抽屉、侧边面板等覆盖层
- 列表 + 详情的位置关系

---

## 模板示例

### Web 后台（左侧导航 + 顶部栏）

```
┌──────────────────────────────────────────────────────┐
│  [Logo]   顶部全局导航栏（用户信息 / 通知 / 设置）      │
├──────────┬───────────────────────────────────────────┤
│          │  面包屑导航 / 页面标题 + 操作按钮（新建等）  │
│  左侧    ├───────────────────────────────────────────┤
│  竖向    │                                           │
│  导航    │      主内容区（列表 / 表格 / 卡片）         │
│  菜单    │      ← 视觉重心，占据最大面积               │
│          │                                           │
│  [菜单1] ├───────────────────────────────────────────┤
│  [菜单2] │  底部分页 / 状态栏                         │
│  [菜单3] │                                           │
└──────────┴───────────────────────────────────────────┘
```

### 列表 + 详情页（双栏布局）

```
┌──────────────────────────────────────────────────────┐
│  顶部导航栏                                          │
├───────────────────┬──────────────────────────────────┤
│                   │                                  │
│  列表区           │  详情区                          │
│  ┌─────────────┐  │  标题                            │
│  │ 条目 1      │  │  状态标签                        │
│  └─────────────┘  │                                  │
│  ┌─────────────┐  │  基本信息表格                    │
│  │ 条目 2 ←    │  │  ...                             │
│  └─────────────┘  │                                  │
│  ┌─────────────┐  │  操作按钮区                      │
│  │ 条目 3      │  │  [编辑] [删除]                   │
│  └─────────────┘  │                                  │
│                   │                                  │
│  [加载更多]       │                                  │
├───────────────────┴──────────────────────────────────┤
│  底部状态栏                                          │
└──────────────────────────────────────────────────────┘
```

### 带弹窗/抽屉的页面

```
┌──────────────────────────────────┐
│  主页面内容                       │
│                        ┌────────┐│
│                        │ 弹窗/  ││
│                        │ 抽屉   ││
│                        │ 内容   ││
│                        │        ││
│                        │[确认]  ││
│                        └────────┘│
│                                  │
└──────────────────────────────────┘
```

---

## 标注规范

- `←` 标注关键区域的作用
- `...` 表示内容省略
- `[按钮文字]` 表示交互元素
- 用 `┌─┐ │ └─┘ ├─┤` 等字符画出区域边界
