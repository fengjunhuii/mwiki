# HTML Sliders 生成器

> 一键生成精美、可交互的 HTML 幻灯片页面

## 核心能力

这个 Skill 帮助你：
1. **分析文稿** - 智能拆解内容，生成分段结构
2. **设计风格** - 多种预设风格 + 自定义配色
3. **生成页面** - 输出独立运行的 HTML 文件，包含动画和交互

## 使用提示

Agent 在**每次**运行任何 `/html-*` 命令时，在回复开头向用户输出以下提示信息：

```
💡 本 Skill 生成独立运行的 HTML 幻灯片，无需服务器，双击即可在浏览器中查看
```

## 可用命令

### `/html-quick` - 一键生成（推荐）

**用途**：一键完成「文稿分析 → 风格设计 → HTML 生成」全流程

**语法**：
```
/html-quick @文稿.md [--style=风格名称] [--output=输出文件.html]
```

**参数**：
| 参数 | 必需 | 默认值 | 说明 |
|------|------|--------|------|
| `@文稿.md` | ✅ | - | 要转换的 Markdown 文件 |
| `--style` | ❌ | `科技暗黑` | 预设风格名称 |
| `--output` | ❌ | `output.html` | 输出 HTML 文件名 |

**可选风格**：`科技暗黑`、`商务咨询`、`极简主义`、`品牌蓝`、`瑞士平面`、`渐变炫彩`

**示例**：
```bash
# 最简用法（使用默认风格）
/html-quick @report.md

# 指定风格
/html-quick @report.md --style=商务咨询

# 指定风格和输出文件
/html-quick @annual-report.md --style=渐变炫彩 --output=./slides/report.html

# 自然语言方式
帮我把 @report.md 转成 HTML 幻灯片，用科技暗黑风格
一键生成 HTML 页面，文稿是 @proposal.md
```

**详细指令**：[commands/quick.md](commands/quick.md)

### `/html-analyze` - 文稿分析

**用途**：分析 Markdown 文稿，提取核心内容，输出结构化的分段清单

**语法**：
```
/html-analyze @文稿.md
```

**输出**：
- 每个分段的标题、内容要点、重点信息
- 推荐的分段类型（hero、card、quote、code、stats等）
- 信息密度评估

**示例**：
```bash
# 分析文稿
/html-analyze @annual-report.md

# 自然语言方式
帮我分析这份文稿 @report.md，拆解成 HTML 分段
把 @proposal.md 转成 HTML 结构
```

**详细指令**：[commands/analyze.md](commands/analyze.md)

---

### `/html-design` - 风格设计

**用途**：选择或定制 HTML 页面视觉风格

**语法**：
```
/html-design
```

**预设风格库**：

| 风格 | 特点 | 配色 | 适用场景 |
|------|------|------|---------|
| 科技暗黑 | 深色背景，霓虹渐变，粒子动画 | 紫蓝粉渐变 | 技术分享、产品演示、黑客松 |
| 商务咨询 | 深蓝稳重，McKinsey 风 | 深蓝+橙色强调 | 方案汇报、咨询报告、投资路演 |
| 极简主义 | 纯白高冷，大量留白 | 白+克莱因蓝 | 产品发布、设计分享、TED 演讲 |
| 品牌蓝 | 蓝紫青配色，现代专业 | 蓝紫青渐变 | 企业培训、通用演示、正式场合 |
| 瑞士平面 | 强烈对比，包豪斯风 | 白底+信号红 | 创意提案、品牌展示、艺术展示 |
| 渐变炫彩 | 多彩渐变，活泼动感 | 彩虹渐变 | 活动宣传、节日祝福、年轻化场景 |

**自定义风格**：
- 主色（必填）：如 `#FF6B00` 或 "橙色"
- 配色方案（可选）：次色、辅助色、背景色、文字色
- 风格关键词（可选）：如 "简约"、"科技感"、"温暖"

**示例**：
```bash
# 启动风格选择（交互式菜单）
/html-design

# 自然语言方式 - 选择预设风格
我想用商务咨询风格
选择科技暗黑风格

# 自然语言方式 - 自定义风格
用我们公司的配色，主色是 #FF6B00，背景用深色
我想要一个温暖的橙色系风格，简约高端
```

**详细指令**：[commands/design.md](commands/design.md)

### `/html-generate` - 生成 HTML

**用途**：根据分段结构和设计规范，生成完整的 HTML 文件

**使用方式**：
```
/html-generate
```

**输出**：
- 完整的 HTML 文件（内联 CSS + JS）
- 文件可直接在浏览器中打开
- 包含滚动揭示动画、弹幕特效、粒子动画等

**详细指令**：[commands/generate.md](commands/generate.md)

## 支持的分段类型

| 类型 | 说明 | 适用内容 |
|------|------|---------|
| `hero` | 首屏大标题区 | 标题、副标题、关键数据 |
| `stats` | 数据统计卡片 | 数字+标签的组合展示 |
| `cards` | 卡片网格 | 多个并列的信息点 |
| `quote` | 引用块 | 名言、重点语录 |
| `code` | 代码块 | 带语法高亮的代码 |
| `flow` | 流程图 | 步骤、流程展示 |
| `highlight` | 高亮区块 | 重点提示、注意事项 |
| `two-col` | 双列布局 | 对比、并列内容 |
| `impact` | 影响力区块 | 受众分析、价值展示 |
| `ending` | 结尾区块 | 总结、行动号召 |

## 特效功能

### 🎆 粒子动画
- 浮动上升的彩色粒子
- 颜色与主题配色协调

### 💬 弹幕特效
- 滚动弹幕评论
- 可自定义弹幕内容
- 点击按钮触发弹幕雨

### ✨ 滚动揭示
- 元素进入视口时渐入
- 层叠延迟动画效果
- 提升页面动感

### 🧭 固定导航
- 顶部固定导航栏
- 毛玻璃效果
- 平滑滚动跳转
