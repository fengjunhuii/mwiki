## 科技暗黑

**来源**：基于 `html_sider.html` 原始模板

**CSS 变量**：
```css
:root {
  --bg: #0a0a0f;
  --bg2: #12121a;
  --card: #1a1a2e;
  --card2: #222240;
  --blue: #00d4ff;
  --purple: #b44aff;
  --pink: #ff4a8d;
  --green: #00ff88;
  --orange: #ff8c00;
  --yellow: #ffd700;
  --red: #ff4444;
  --text: #e8e8f0;
  --text2: #a0a0b8;
  --muted: #666680;
  --gm: linear-gradient(135deg, #00d4ff, #b44aff, #ff4a8d);
  --gf: linear-gradient(135deg, #ff4444, #ff8c00, #ffd700);
}
```

**特点**：
- 深色背景（#0a0a0f）
- 霓虹渐变（蓝→紫→粉）
- 玻璃拟态效果
- 粒子动画
- 弹幕特效

**适用场景**：技术分享、产品演示、黑客松、技术博客

## 渐变炫彩

**CSS 变量**：
```css
:root {
  --bg: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
  --bg2: rgba(255,255,255,0.05);
  --card: rgba(255,255,255,0.1);
  --rainbow: linear-gradient(90deg, #ff6b6b, #feca57, #48dbfb, #ff9ff3, #54a0ff);
  --text: #ffffff;
  --text2: rgba(255,255,255,0.8);
}
```

**特点**：
- 多彩渐变背景
- 活泼动感
- 年轻化设计
- 玻璃拟态卡片

**适用场景**：活动宣传、节日祝福、年轻化品牌、娱乐内容

## 风格选择建议

| 场景 | 推荐风格 | 理由 |
|------|---------|------|
| 技术分享会 | 科技暗黑 | 科技感强，代码高亮好 |
| 投资路演 | 商务咨询 | 专业稳重，数据清晰 |
| 产品发布会 | 极简主义 | 聚焦产品，减少干扰 |
| 企业内训 | 品牌蓝 | 中性专业，适合长时间阅读 |
| 创意提案 | 瑞士平面 | 强烈视觉冲击 |
| 社交媒体 | 渐变炫彩 | 吸引眼球，传播性强 |
