# /html-design 命令详解

## 执行流程

### 1. 展示风格选项

```
🎨 请选择 HTML 页面风格：

预设风格：
1. 科技暗黑 - 深色背景，霓虹渐变，粒子动画
2. 商务咨询 - 深蓝稳重，McKinsey 风格
3. 极简主义 - 纯白高冷，大量留白
4. 品牌蓝 - 蓝紫青配色，现代专业
5. 瑞士平面 - 强烈对比，包豪斯风
6. 渐变炫彩 - 多彩渐变，活泼动感

自定义：
7. 自定义风格 - 输入你的品牌色和偏好

请输入数字选择，或直接说风格名称：
```

### 2. 处理用户选择

#### 选择预设风格
直接加载对应的风格配置，输出设计规范。

#### 选择自定义风格
引导用户提供：
1. **主色**（必填）
   - 格式：`#FF6B00` 或颜色名称如 "橙色"
   - 用途：强调色、按钮、重点文字

2. **背景风格**（可选）
   - 深色 / 浅色 / 渐变
   - 默认：根据主色自动推荐

3. **风格关键词**（可选）
   - 如：简约、科技感、温暖、高端、活泼
   - 用于调整整体氛围

### 3. 输出设计规范

```markdown
## 设计规范

### 风格信息
- **风格名称**: 科技暗黑
- **风格类型**: 预设

### CSS 变量
```css
:root {
  --bg: #0a0a0f;        /* 背景色 */
  --bg2: #12121a;       /* 次级背景 */
  --card: #1a1a2e;      /* 卡片背景 */
  --blue: #00d4ff;      /* 蓝色 */
  --purple: #b44aff;    /* 紫色 */
  --pink: #ff4a8d;      /* 粉色 */
  --text: #e8e8f0;      /* 主文字 */
  --text2: #a0a0b8;     /* 次级文字 */
  --gm: linear-gradient(135deg, #00d4ff, #b44aff, #ff4a8d);
}
```

### 组件样式
- **导航栏**: 固定顶部，毛玻璃效果
- **卡片**: 圆角 16px，渐变边框
- **按钮**: 圆角 25px，渐变背景
- **代码块**: 深色背景，语法高亮

### 动画效果
- **滚动揭示**: 渐入 + 上移 25px
- **粒子动画**: 浮动上升，5 种颜色
- **弹幕特效**: 水平滚动，随机颜色

### 字体
- **主字体**: Noto Sans SC (思源黑体)
- **代码字体**: Courier New
```

## 预设风格详情

### 科技暗黑
```css
:root {
  --bg: #0a0a0f;
  --bg2: #12121a;
  --card: #1a1a2e;
  --blue: #00d4ff;
  --purple: #b44aff;
  --pink: #ff4a8d;
  --green: #00ff88;
  --text: #e8e8f0;
}
```
特点：深色背景、霓虹渐变、玻璃拟态、粒子动画

### 商务咨询
```css
:root {
  --bg: #0f172a;
  --bg2: #1e293b;
  --card: #334155;
  --blue: #3b82f6;
  --orange: #f97316;
  --text: #f1f5f9;
}
```
特点：深蓝稳重、橙色强调、McKinsey 风格

### 极简主义
```css
:root {
  --bg: #ffffff;
  --bg2: #f8fafc;
  --card: #f1f5f9;
  --blue: #0055ff;
  --text: #0f172a;
}
```
特点：纯白背景、大量留白、克莱因蓝点缀

### 品牌蓝
```css
:root {
  --bg: #0c1222;
  --bg2: #131b2e;
  --card: #1a2540;
  --blue: #4f8cff;
  --purple: #8b5cf6;
  --cyan: #06b6d4;
  --text: #e2e8f0;
}
```
特点：蓝紫青配色、现代专业

### 瑞士平面
```css
:root {
  --bg: #ffffff;
  --bg2: #f5f5f5;
  --card: #ffffff;
  --red: #ff0000;
  --black: #000000;
  --text: #000000;
}
```
特点：强烈对比、包豪斯风格、信号红

### 渐变炫彩
```css
:root {
  --bg: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
  --card: rgba(255,255,255,0.1);
  --rainbow: linear-gradient(90deg, #ff6b6b, #feca57, #48dbfb, #ff9ff3);
}
```
特点：多彩渐变、活泼动感、年轻化

## 自定义流程

1. 询问主色
2. 根据主色推荐配色方案
3. 询问背景风格偏好
4. 生成完整 CSS 变量
5. 输出设计规范供确认
